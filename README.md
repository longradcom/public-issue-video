# Public Issue Video — Market Intelligence & Strategy

Interactive research microsite: market evidence, segment scoring, competitor landscape, pricing and unit economics, go-to-market experiments and source library for Public Issue Video.

**Live:** https://longradcom.github.io/public-issue-video/

The whole site is one self-contained `index.html` (inline CSS, JS and research data). No build step, dependencies or server code. Edit `index.html` and push to `main`; GitHub Pages redeploys automatically.
